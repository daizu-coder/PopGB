PopGB (SHARP Brain PW-G5300 Windows CE port) - Third-party licenses
===================================================================

This file records the provenance and licensing of every component that
goes into the built binary (AppMain.exe), and should ship alongside it.
The reasoning behind it, and the files that are in the tree but not
built, are in sys/ce/LICENSING.md.

Quick summary:
  - PopGB as a whole is distributed under the GNU GPL, version 2
    (GPL-2.0), on the same terms as upstream gnuboy (COPYING at the
    repository root; sys/ce/LICENSE, sections 1 and 3).
  - PopGB's own code is MIT, and the menu mascot and the app icon are
    CC0 1.0.
  - inflate.c and XZ Embedded are public domain; miniz / tinfl is MIT.
  - The Shinonome bitmap font is effectively Public Domain.
  - The Galmuri font is under the SIL Open Font License 1.1.
  - All of these are GPL-compatible. No bundled component carries a
    non-commercial clause. No game ROMs are included.


gnuboy core (Game Boy / Game Boy Color emulator)
------------------------------------------------
Files: the repository-root C sources compiled by Makefile.ce's OBJS
(lcd.c, refresh.c, lcdc.c, palette.c, cpu.c, mem.c, rtc.c, hw.c,
sound.c, fastmem.c, loader.c, save.c, emu.c, rcvars.c and their
headers).
Upstream: https://github.com/rofl0r/gnuboy (commit c367bb4), the
revived "gnuboy" line (README: gnuboy 1.0.3 / 1.0.4), originally by
Laguna and Gilgamesh (see docs/CREDITS).
Copyright (C) 2000-2001 Laguna and Gilgamesh; portions contributed by
other authors (docs/CREDITS).
License: GNU General Public License, version 2 (GPL-2.0), same terms
as upstream - full text in COPYING at the repository root. gnuboy's
main.c notice (reproduced in sys/ce/LICENSE, section 3) says "version 2
of the License, or (at your option) any later version", but most core
files carry no notice of their own, so this port does not state
"or later" for the whole.
Local modifications for this port are deliberately minimal and are
listed in sys/ce/LICENSING.md; they do not change the license.

  http://www.on.cs.keio.ac.jp/~yasu/

"jiskan16" font (see the upstream project's AUTHORS file for the exact

  https://github.com/code4fukui/shinonome-font

This build converts the original 16dot BDF-like glyph sources
(kanjic/JIS X0208, latin1/ISO8859-1, hankaku/JIS X0201) into a C glyph
table at build time on the developer's machine (sys/ce/tools/
shinonome2c.py); no part of the conversion tooling or the upstream
source tree ships on the device, only the resulting glyph bitmaps
(sys/ce/ce_shinonome16.h).


Galmuri font (Galmuri14, GalmuriMono11)
---------------------------------------
Upstream: https://github.com/quiple/galmuri
Version used: 2.40.4 (commit 71e1cac)
Copyright (c) 2019-2025 Lee Minseo (quiple@quiple.dev)
License: SIL Open Font License, Version 1.1 (full text below)

PopGB embeds glyph data for its Japanese/English menu text. The default
build (make, CE_FONT=galmuri14) uses glyphs converted from Galmuri14;
the characters Galmuri14 does not have (Greek, Cyrillic and some math
symbols) are filled in from the Shinonome 16dot font described above.

The glyph bitmaps of dist/Galmuri14.bdf (and, for the optional
CE_FONT=galmuri11 build, dist/GalmuriMono11.bdf) were converted by
sys/ce/tools/galmuri2c.py into the C glyph tables
sys/ce/ce_galmuri14.h and sys/ce/ce_galmuri11.h (a Modified Version under the OFL: format
conversion, character subset, vertical placement, and missing glyphs
filled from Shinonome 16dot). No Reserved Font Name is declared after
the copyright statement in the upstream ofl.md. These glyph tables
remain under the SIL Open Font License 1.1; the rest of PopGB is not
covered by it.
